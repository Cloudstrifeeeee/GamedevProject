# GamedevProject
# Game Title - Labyrinth of Hades
# Game Genre - Text-Based RPG / Mythological Fantasy / Dungeon Crawler
# Game Mechanics - Players choose a unique class and venture through a dungeon with randomly generated events. Combat is turn-based, featuring normal attacks and special skills. Players earn gold and EXP from battles, manage inventory through a shop system, and survive increasingly dangerous encounters across multiple rooms.
